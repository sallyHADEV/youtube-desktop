# YouTube Desktop

YouTube 전용 데스크톱 앱입니다. Google 계정으로 로그인해 구독·시청 기록을 그대로 쓰면서, **그 로그인 세션으로는 YouTube 밖 Google 서비스에 갈 수 없습니다.** Gmail·포토·드라이브·내 Google 계정은 모두 차단됩니다.

> [English](README.md) · [개발 문서](DEVELOPMENT.ko.md)

## 만든 이유

브라우저 탭에서 YouTube를 보면 같은 로그인 세션으로 나머지 Google 서비스가 클릭 한 번 거리에 있습니다. 이 앱은 **YouTube만 간편하게** 쓰려고 만들었습니다 — 한 번 로그인하고, 보고, 계정은 YouTube 안에 갇혀 있게.

- 패스키(Windows Hello) 로그인 지원
- 한 번 로그인하면 앱을 껐다 켜도 유지
- 창 전체가 다크 테마 (타이틀바 포함)
- 마우스 제스처로 앞·뒤 이동·창 닫기, `R` 키로 영상 회전

## 설치

`dist` 폴더의 두 파일 중 하나를 쓰면 됩니다.

| 파일 | 설명 |
| --- | --- |
| `YouTube Desktop Setup 1.1.0.exe` | 설치본. 시작 메뉴·바탕화면 바로가기가 생깁니다 |
| `YouTube Desktop 1.1.0.exe` | 포터블. 설치 없이 더블클릭만 하면 됩니다 |

코드 서명이 없어서 처음 실행할 때 Windows SmartScreen 경고가 뜹니다. **추가 정보 → 실행**으로 넘어가면 됩니다.

Windows 11 기준입니다. Windows 10에서도 동작하지만 타이틀바는 시스템 색을 따릅니다.

## 로그인

메뉴 → **계정 → Google 계정으로 로그인**.

패스키가 등록된 계정이면 Windows Hello 창이 뜨고, 지문·PIN·얼굴로 인증하면 끝납니다. 비밀번호 로그인도 됩니다.

로그인 상태는 `%APPDATA%\YouTube Desktop`에 저장되어 앱을 껐다 켜도 유지됩니다.

**로그아웃**은 메뉴 → **계정 → 로그아웃 (세션 삭제)**. 쿠키·캐시·저장소를 모두 지웁니다.

## 마우스 제스처

**오른쪽 버튼을 누른 채 드래그**하면 페이지를 오갈 수 있습니다.

| 동작 | 결과 |
| --- | --- |
| ← 왼쪽으로 드래그 | 뒤로 |
| → 오른쪽으로 드래그 | 앞으로 |
| ↓ 아래로 내렸다가 → 오른쪽으로 (**ㄴ 모양**) | 창 닫기 |

60픽셀 이상 움직여야 인식합니다. 직선 제스처는 세로로 더 많이 움직이면 무시하고, 제자리 우클릭은 평소처럼 메뉴가 뜹니다.

ㄴ 제스처는 **그 제스처를 그린 창**을 닫습니다. 새 창에서 그리면 새 창만, 메인 창에서 그리면 앱이 종료됩니다.

키보드로는 `Alt+←` / `Alt+→`, 메뉴에서는 **탐색 → 뒤로 / 앞으로**도 됩니다.

## 영상 회전

**`R`** 키를 누르면 영상이 시계 방향으로 90도씩 돌아갑니다. 네 번 누르면 원래대로 돌아옵니다. 세로로 찍힌 영상이 눕혀져 올라온 경우에 유용합니다.

**영상만 회전합니다** — 플레이어 컨트롤과 페이지는 그대로이고, 회전한 영상은 플레이어 안에 들어오도록 자동으로 축소됩니다. 다른 영상으로 넘어가면 회전이 초기화되고, 검색창에 입력 중일 때는 `R`이 동작하지 않습니다.

## 차단되는 것

| | |
| --- | --- |
| 앱 안에서 열림 | YouTube 전체, YouTube Music, YouTube Studio, 로그인 화면 |
| **차단** | Gmail, Google 포토, 드라이브, 문서, 캘린더, 내 Google 계정, Google 검색 등 |
| 기본 브라우저로 | YouTube와 무관한 링크 (영상 설명의 외부 링크 등) |

차단된 Google 서비스를 열려고 하면 안내창이 뜨고, 거기서 **기본 브라우저에서 열기**를 고를 수 있습니다. 그때는 이 앱의 로그인 세션을 쓰지 않습니다.

## 문제 해결

### 로그인이 중간에 멈추거나 반복될 때

중단된 로그인이 어중간한 세션을 남기면 Google이 이미 로그인된 것으로 판단해 인증을 다시 돌리지 않습니다. 메뉴 → **계정 → 로그아웃 (세션 삭제)** 후 다시 로그인하세요.

### 앱이 실행되지 않을 때

이미 창이 떠 있으면 새로 실행해도 기존 창만 앞으로 나옵니다. 작업 표시줄이나 다른 가상 데스크톱을 확인해 보세요.

### 아이콘이 예전 것으로 보일 때

Windows 아이콘 캐시 때문입니다. 탐색기에서 `F5`로 새로고침하거나, 그래도 안 되면 탐색기를 재시작하세요:

```bash
taskkill /f /im explorer.exe && start explorer.exe
```

### 로그 위치

문제가 생기면 이동 경로와 차단 기록이 여기 남습니다:

```
%APPDATA%\YouTube Desktop\ytd.log
```

계정 토큰이 들어있는 주소의 쿼리 부분은 기록하지 않습니다.

## 알려진 제약

- YouTube 아바타 메뉴의 "Google 계정 관리"는 설계상 차단됩니다. 안내창에서 기본 브라우저로 열 수 있습니다.
- 멤버십·Super Thanks 결제는 결제창이 앱 안에 뜨는 경우에만 동작합니다. 전체 페이지로 넘어가는 흐름이면 차단됩니다.
- 광고 차단 기능은 없습니다.
- macOS·Linux에서는 패스키가 동작하지 않습니다. Electron이 두 플랫폼에서 WebAuthn 화면을 제공하지 못하기 때문입니다 ([electron#24573](https://github.com/electron/electron/issues/24573)).

## 소스에서 실행

```bash
npm install
npm start
```

> **PowerShell에서 `npm`이 거부된다면** (`이 시스템에서 스크립트를 실행할 수 없으므로 ... npm.ps1`)
> `npm` 대신 `npm.cmd`를 쓰세요. PowerShell이 `npm`을 `npm.ps1` 스크립트로 해석하는데 실행
> 정책에 막히는 것으로, 실행 정책을 바꿀 필요는 없습니다.
>
> ```bash
> npm.cmd start
> ```

설치본을 직접 만들려면 `npm run dist` — 결과물은 `dist` 폴더에 생깁니다.

## 고지

비공식 개인용 클라이언트입니다. Google 및 YouTube와 제휴·후원 관계가 없습니다. YouTube는 Google LLC의 상표이며, 앱 아이콘은 YouTube 로고가 아닌 일반적인 재생 버튼 모양입니다.
